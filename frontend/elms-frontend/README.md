# 🏢 Employee Leave Management System

A full-stack Employee Leave Management System built using
ASP.NET Core Web API, React, SQL Server and JWT authentication.

## 🚀 Features

- Employee management
- Manager team management
- Leave request submission
- Leave approval/rejection
- Leave balances
- Holiday calendar
- Notifications
- Role-based authorization
- JWT authentication
- Admin dashboard
- Manager dashboard
- Employee dashboard

## 🛠️ Tech Stack

### Backend
- ASP.NET Core Web API
- C#
- Entity Framework Core
- SQL Server
- JWT Authentication

### Frontend
- React
- React Router
- Axios
- CSS

## 👥 Roles

### Admin
- Manage employees
- Manage departments
- Manage leave types
- Manage holidays
- View and approve leave requests

### Manager
- View team members
- Approve/reject team leave requests
- Receive notifications

### Employee
- Apply for leave
- View leave history
- View leave balances
- Cancel pending requests
